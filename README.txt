Bouzouki Fretboard Internalizer v1.1

Open index.html in Safari/Chrome. The app is self-contained and works offline after loading.

v1.1 updates:
- Added chart/tab course-order setting: C-F-A-D or D-A-F-C vertical display.
- Added Guided Session setting to skip the warm-up and start directly at the drill blocks.
- Added custom per-pitch sharp/flat note-name mapping, so the app can mix names like Bb and F#.
- Rebuilt the quiz area into dozens of separate 10-second quiz types categorized by course, fretboard geography, scales/degrees, musical context, speed recall, and daily-plan repair.
- Quiz prompts and daily sessions include voice guidance using browser speech synthesis.

Physical bouzouki tuning used by the app: bottom/floor D, then A, then F, top/ceiling C.
